# Sueta Shortcut

Простое приложение для быстрого доступа к системным разделам.

Приложение не анализирует данные автоматически, не отсылает их в Интернет. Оно просто открывает нужные папки, журналы, ветки реестра и внешние инструменты в пару кликов. 

## Требования

- Windows
- Python `3.10+`
- `PySide6`

## Запуск

Приложение запрашивает права администратора при запуске.

## Важно

- приложение не парсит `Prefetch`, `Amcache` и другие артефакты
- приложение рассчитано на ручной просмотр
- использовать только там, где у вас есть разрешенный доступ
