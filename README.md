# Sueta Shortcut

`Sueta Shortcut` — простая Windows-утилита для быстрого доступа к системным артефактам.

Приложение не анализирует данные автоматически. Оно просто открывает нужные папки, журналы, ветки реестра и внешние инструменты в пару кликов.

## Требования

- Windows
- Python `3.10+`
- `PySide6`

## Запуск

Приложение запрашивает права администратора при запуске.

## Важно

- приложение не парсит `Prefetch`, `Amcache` и другие артефакты
- приложение рассчитано на ручной просмотр
- использовать только там, где у вас есть разрешенный доступ
