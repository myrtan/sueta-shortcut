# sueta-shortcut
Very simple and tool for manual PC checks. It helps you quickly open useful registry paths, system folders, browser traces, and Steam data in one place.

Простая тулза для ручной и поверхностной проверки ПК на Windows
Помогает быстро открыть нужные разделы реестра, системные папки, браузерные следы, данные Steam и другие полезные места в одном окне.

### Возможности

быстрый доступ к важным веткам реестра
открытие системных папок и временных файлов
быстрый переход к следам браузеров
быстрый доступ к данным Steam
просмотр даты установки Windows
компактный интерфейс для повседневной работы

### Для чего нужен

Программа создана как вспомогательный инструмент для ручной проверки ПК.  
Она не выполняет автоматическое сканирование и не удаляет файлы.  
Создана чтобы ускорить доступ к нужным местам системы и упростить процесс проверки.

### Требования

- Python 3.10+ для запуска из исходника
